# Guía de contribución – Team Notes

Este documento explica las normas básicas para trabajar en el repositorio, crear ramas, realizar commits y abrir Pull Requests (PR).


## Requisitos previos

Antes de empezar, asegurate de tener instalado:

- **Git**  
- **Python 3.x**  
- Una cuenta en **GitHub** y acceso al repositorio del equipo.

Cloná el proyecto:

```bash
git clone https://github.com/<usuario>/team-notes.git
cd team-notes
